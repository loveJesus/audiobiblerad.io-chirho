# Audio Bible Radio: web publication

The web radio is live at https://audiobiblerad.io, with https://www.audiobiblerad.io also serving it. The owner's "i think publish it" resumed his paused domain-deployment request. The project Worker is `audiobiblerad-io-chirho`, version `1535e80b-a253-463b-a24b-5a08041fd322`, deployed once from release inputs `96e232d`. The existing account was used, with this domain on a Free zone; no signup, paid-plan change, native/store record, key request or outreach occurred.

Fresh gates passed: check 0 errors/0 warnings, lint, 195 unit/component tests, 21 browser tests, build and Wrangler dry-run. Strict standalone checks cover the release/probe scripts. The prepared directory is 1,838,281 bytes across 417 files; 414 deployable public assets total 1,833,649 bytes. All 414 match the production HTTPS responses byte for byte. Package scans are clean, 62 configured credential values are absent, and only the nine original WAVs are packaged. No Scripture audio was copied or re-hosted.

On the normal production URL in a fresh Chromium context, five real upstream streams played and advanced: Hays, Souer, Hindi ULB, Davar Hindi and LibriVox Spanish. Their credits and source/licence links were present. First tap to the first Scripture playing event was 251.9 ms; the five measurements were 251.9, 29.3, 130.7, 152.4 and 1,283.6 ms. The catalogue's exact JSON/CORS headers, credits route and private-path 404s pass. Normal apex and www HTTPS return matching app HTML. Both old and new nameserver sets now answer usable addresses.
